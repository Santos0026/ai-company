# AIタスク台帳プロトコル — 「言ったのに反応がない」を根絶する

制定: 2026-08-31（オーナー指示: Javisへの依頼が無応答のまま放置された問題を受けて）

## 解決したい問題

オーナーがAI（Javis等）に依頼 → 相手が反応しているのか不明 → 時間が経って
オーナー自身が「反応ないですよ」と言い直す。**この確認コストをオーナーから取り除く。**

## 原則

1. **口頭依頼は存在しない扱い**: オーナーがAIに出した依頼は、必ず
   `operations/tasks/OPEN_TASKS.md` に1行追加される（依頼を受けたAI、または
   最初にそれを知ったAIが記載する。オーナーに書かせない）
2. **ACK義務**: 依頼されたAIは着手前にまずステータスを `ACK`（受領）に更新する。
   **ACKがない依頼＝届いていない依頼**として扱い、監視対象になる
3. **期限必須**: すべてのタスクに期限を付ける。不明なら「24時間以内」がデフォルト
4. **完了は成果物リンクで示す**: 「やりました」ではなくコミット・ファイルパス・
   URLを台帳に記載して `DONE` にする

## ステータス

`REQUESTED`（依頼済・未応答） → `ACK`（受領） → `IN_PROGRESS` → `DONE` / `BLOCKED`

## ウォッチドッグ（自動監視）

定期実行のAIセッションが `OPEN_TASKS.md` を確認し:

- `REQUESTED` のまま6時間以上 → **無応答**としてオーナーに報告し、代行可能なら代行する
- 期限超過 → 超過理由の確認と再割り当て案をオーナーに報告する

オーナーが自分で催促することは想定しない。催促はウォッチドッグの仕事。

## このリポジトリで作業するAIへ（毎セッション必須）

セッション開始時に `OPEN_TASKS.md` を確認し、自分宛て（Javis/AIカンパニー宛て含む）の
`REQUESTED` があれば即ACKして着手、または代行可否を判断すること。
