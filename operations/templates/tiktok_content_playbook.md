## 1. 週次スケジュール（オーナーの実稼働 = 週90分）

| 曜日 | 担当 | 内容 | 所要 |
|------|------|------|------|
| 金 | Ryo | 翌週の台本3本を作成しオーナーへ共有 | — |
| 土 or 日 | **オーナー** | **収録日：3本をまとめ撮り** | **90分** |
| 月・水・金 | Sora | TikTok投稿 → Reels転載 → Threads文章版投稿 | — |
| 投稿当日 | Sora | コメント全返信・反応者のプロフィール確認・DM打診 | — |
| 木 | Sora | 週次SNSレポートをJobsへ提出 | — |

**収録日のルール**
- 同じ服・同じ場所で3本連続撮影する（着替え・移動をしない）
- 1本あたり撮り直しは最大2回。完璧を狙わない
- 編集は「冒頭カット＋テロップ」のみ。凝らない

## 2. 動画の型（全本共通・60〜90秒）

```
0〜3秒   フック    ：一文だけ。ここで9割が決まる
3〜10秒  自己開示  ：「年間1,000人の個人事業主を取材している者です」
10〜50秒 中身      ：取材で聞いた具体エピソード（数字・固有の状況を必ず入れる）
50〜70秒 問いかけ  ：「あなたはどうですか？」でコメントを取りに行く
70〜85秒 CTA      ：固定文言（下記）
```

**CTA固定文言（全動画共通・変えない）**
> 「個人でお店をやってる方の取材、いま募集してます。
> プロフィールのリンクから、一言送ってもらえたら大丈夫です。」

> 押さない。売らない。**「取材を募集している」**という立ち位置を絶対に崩さないこと。
> これが売り込みに見えずに接触できる唯一の入口であり、既存DM営業との決定的な差になる。

## 3. フック集（冒頭3秒・そのまま使える）

**① 取材本音型**
- 「月商80万の整体院オーナーが、一番怖いのは『売上が落ちること』じゃないって言ってました」
- 「取材で一番よく聞く後悔、ダントツで1位はこれです」
- 「『開業して3年、いま初めて人に相談しました』って言われた話をします」

**② 問いかけ型**
- 「独立して一番後悔したこと、正直に言える人います？」
- 「お客さんが来ない日と、来すぎる日。どっちがしんどいですか？」
- 「個人事業主のみなさん、去年の確定申告、自信ありますか？」

**③ ノウハウ型**
- 「個人サロンのInstagram、プロフィールのここだけ直せば予約入ります」
- 「予約が埋まってるのにお金が残らない店の共通点、3つあります」
- 「1人でお店やってる人が、最初に外注すべきなのは撮影じゃないです」

## 4. 台本サンプル（そのまま読める）

### サンプル①：取材本音型

> 月商80万の整体院オーナーが、
> 「一番の経営リスクは、自分が倒れることだ」って言ってたんですよ。
>
> 地域の個人事業主を年間1,000人くらい取材している者です。
>
> その方、売上は安定してるし、予約もほぼ埋まってる。
> でも、自分が1週間寝込んだら、その瞬間に収入ゼロなんですよね。
>
> 「もし事故にあったら」「子どもの学費が重なる時期に廃業したら」
> ——考えたことはあったけど、調べたことは一度もなかった、と。
>
> これ、1人でお店やってる人ほど当てはまると思ってて。
>
> あなたはどうですか？
> 自分が倒れたときのこと、考えたことありますか？
>
> 個人でお店をやってる方の取材、いま募集してます。
> プロフィールのリンクから、一言送ってもらえたら大丈夫です。

### サンプル②：問いかけ型

> 独立して一番後悔したこと、正直に言える人います？
>
> 取材でこれを聞くと、めちゃくちゃ多いのが「お金の話を後回しにしたこと」なんですよ。
>
> 集客とか技術には本気で投資してきた。
> でも保険とか年金とか、事業のたたみ方とか、
> 「いつか調べよう」で3年経ってた、って。
>
> しかも聞ける相手がいない。
> 同業の友達には言いづらいし、家族にも心配かけたくないし。
>
> 独立3年以内の方、「後悔ポイント」コメントで教えてください。
> 同じところで詰まってる人、絶対いるので。
>
> 個人でお店をやってる方の取材、いま募集してます。
> プロフィールのリンクから、一言送ってもらえたら大丈夫です。

> Threads用の文章版は `operations/templates/threads_content_calendar.md` の台本をそのまま流用可。
> **同じ台本を「読む＝TikTok」「書く＝Threads」で二重に使うのが本プレイブックの核心。**

## 5. プロフィール設計（Phase 0で必ず書き換える）

```
【名前欄】
〇〇｜地域のお店を取材する人

【自己紹介】
年間1,000人の個人事業主を取材してます
サロン・整体院・個人店オーナーの本音を発信
▼取材のご依頼・ご相談はこちら
```

**リンクは1本だけ**（公式LINE）。リンクまとめサービスを挟まない — 1クリック増えるごとに到達は半分になる。

## 6. コメント → DM → アポの流れ（Sora担当）

### STEP 1：コメントは全部返す（投稿当日中）
返信は必ず**問いかけで終える**。会話が続いた相手だけが見込み客。

### STEP 2：プロフィール確認
- 個人事業主か（サロン・整体・美容・個人店）
- 地域は対象内か
- Instagram／LINEへの導線があるか

### STEP 3：DM打診
> コメントありがとうございます！
> 〇〇（業種）をされてるんですね😊
> よかったら少しお話聞かせてもらえませんか？
> 取材のご案内もできるので、DM送っても大丈夫ですか？

### STEP 4：以降は既存フローに合流
DM許可後の説明文は、Ryo設計の既存スクリプトを使用。
アポ確定後は **Kaiの日次ログに「TikTok経由」タグで記録** し、初回電話フローへ引き継ぐ。

> **重要**：ここで新しい営業フローを作らないこと。既存の初回電話→インタビュー→FP面談の流れに合流させる。流入経路タグだけが新しい。

## 7. LIVE配信（週1回・30分／要件クリア済み）

| 項目 | 内容 |
|------|------|
| 頻度 | 週1回・30分（曜日固定） |
| テーマ | 「個人事業主のお金と集客、なんでも聞く枠」 |
| 目的 | ①濃い接触からのLINE誘導（本命）②ギフト収入（副次） |
| やること | 質問に答える・取材の裏話をする・最後に必ずLINE導線を口頭で案内 |
| やらないこと | 保険商品の説明、金融の断定的アドバイス |

## 8. 計測（毎投稿・スプレッドシートに記録）

| 日付 | フォーマット | フック | 再生 | いいね | コメント | プロフ遷移 | LINE登録 |
|------|------------|--------|------|--------|---------|-----------|---------|
| | ①取材本音 / ②問いかけ / ③ノウハウ | | | | | | |

**月末にやること**：`プロフ遷移 ÷ 再生` が最も高かったフックを特定し、翌月はその型を厚くする。
**再生数が最大の本ではなく、LINE登録が最大の本を正解とする。**

---

## 9. 禁止事項

- 毎日投稿しようとする（週2〜3本の継続が最優先）
- 台本なしで撮る（収録が長引き、翌週から続かなくなる）
- ジャンルを広げてバズを狙う（導線に乗らない層が増えるとターゲティングが濁る）
- 保険・金融の断定的な発信
- 取材した方の情報を、許可なく特定できる形で出す
