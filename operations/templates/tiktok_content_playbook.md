**対象**: オーナー（撮影担当）／ Ryo（台本）／ Sora（投稿・コメント対応）
**上位方針**: `company/marketing/SNS_MONETIZATION_STRATEGY.md`
**到達計画**: `operations/templates/tiktok_growth_plan_10k.md`

> **2026-08-28 改訂**: フォロワー1万人を目標に設定したため、動画尺を **60〜90秒 → 20〜35秒** に、
> 投稿本数を **週2〜3本 → 週5本** に変更。**オーナーの撮影時間は週90分のまま**（短尺化により1回の収録で10本撮れるため）。

## 1. 週次スケジュール（オーナーの実稼働 = 週90分・変更なし）

| 曜日 | 担当 | 内容 | 所要 |
|------|------|------|------|
| 金 | Ryo | 翌週の短尺台本10本ぶんを作成しオーナーへ共有 | — |
| 土 or 日 | **オーナー** | **収録日：短尺10〜12本をまとめ撮り** | **90分** |
| 月〜金 | Sora | 1日1本投稿（TikTok → Reels転載 → 週3本はThreads文章版） | — |
| 投稿当日 | Sora | コメント全返信・反応者のプロフィール確認・DM打診 | — |
| 木 | Sora | 週次グロースレポートをJobsへ提出 | — |

**収録日のルール**
- 同じ服・同じ場所で連続撮影する（着替え・移動をしない）
- **1本あたり実撮影3〜5分**。20〜35秒の台本なら覚える負荷も撮り直しも軽い
- 撮り直しは1本につき最大2回。完璧を狙わない
- 編集は「冒頭カット＋テロップ」のみ
- **10本撮れたら2本はストックに回す**（伸びなかった週の補填・体調不良の保険）

> 週5本のうち **1〜2本は「コメントに動画で返信」** で埋める。撮影日以外に単独で撮れるうえ、
> ネタを考える必要がなく、既存視聴者の再訪を生む。実質、撮影負荷ゼロで本数が増える。

## 2. 動画の型（全本共通・**20〜35秒**）

```
0〜2秒   フック    ：いきなり結論／いきなりセリフ。説明から入らない
                    発話とテロップを必ず同時に出す（音声オフ視聴者が約半分）
2〜5秒   名乗り    ：「個人事業主を年間1,000人取材してる者です」
5〜22秒  中身      ：エピソードを1つだけ。数字か固有の状況を必ず入れる
22〜30秒 問いかけ  ：答えが割れる問いで終える（コメント率が配信量を決める）
```

**尺の絶対ルール**：**35秒を超えたら中身を削る**。エピソードを2つ入れない。
配信量を決めるのは**視聴完了率**であり、25秒で80%完視聴のほうが、60秒で30%完視聴より圧倒的に伸びる。

**シリーズ通し番号を必ず入れる**（フォロワー転換率がここで倍変わる）

```
テロップ例：  取材で聞いた本音 #37
```

番号があると「他の回も見たい」が発生し、プロフィール遷移 → 過去動画の連続視聴 → フォロー、が繋がる。
**単発バズはフォローされない。続きがあるものだけがフォローされる。**

**CTAの扱い（重要な変更）**

短尺では**毎回CTAを入れない**。20〜35秒でCTAまで入れると中身が死に、完視聴率が落ちる。

| 本数 | CTA |
|------|-----|
| 週5本のうち4本 | **CTAなし**。問いかけで終える（完視聴率とコメント率を最大化） |
| 週5本のうち1本 | 下記のCTA固定文言を入れる（募集回） |

> 「個人でお店をやってる方の取材、いま募集してます。
> プロフィールのリンクから、一言送ってもらえたら大丈夫です。」

押さない。売らない。**「取材を募集している」**という立ち位置を絶対に崩さないこと。
CTAは動画本数ではなく**プロフィールと固定動画で常時効かせる**のが短尺運用の作法。

## 3. フック集（冒頭3秒・そのまま使える）

**① 取材本音型**
- 「月商80万の整体院オーナーが、一番怖いのは『売上が落ちること』じゃないって言ってました」
- 「取材で一番よく聞く後悔、ダントツで1位はこれです」
- 「『開業して3年、いま初めて人に相談しました』って言われた話をします」

**② 問いかけ型**
- 「独立して一番後悔したこと、正直に言える人います？」
- 「お客さんが来ない日と、来すぎる日。どっちがしんどいですか？」
- 「個人事業主のみなさん、去年の確定申告、自信ありますか？」

**③ ノウハウ型**
- 「個人サロンのInstagram、プロフィールのここだけ直せば予約入ります」
- 「予約が埋まってるのにお金が残らない店の共通点、3つあります」
- 「1人でお店やってる人が、最初に外注すべきなのは撮影じゃないです」

## 4. 台本サンプル（20〜35秒・そのまま読める）

### サンプル①：取材本音型（約28秒・CTAなし）

> 「一番怖いのは、売上が落ちることじゃないんです」
>
> 月商80万の整体院オーナーが言ってました。
> 個人事業主を年間1,000人くらい取材してる者です。
>
> 売上は安定してる。予約もほぼ埋まってる。
> でも自分が1週間寝込んだら、その瞬間に収入ゼロ。
>
> 「考えたことはあったけど、調べたことは一度もなかった」って。
>
> これ、1人でお店やってる人ほど当てはまると思うんですけど、
> みなさん、自分が倒れたときのこと考えたことあります？

### サンプル②：問いかけ型（約25秒・CTAなし）

> 独立して一番後悔したこと、聞いてまわってるんですけど、
> ダントツ1位が「お金の話を後回しにしたこと」でした。
>
> 集客と技術には本気で投資してきた。
> でも保険とか年金とか、「いつか調べよう」で3年経ってた、と。
>
> しかも聞ける相手がいない。
> 同業には言いづらいし、家族には心配かけたくないし。
>
> 独立3年以内の人、後悔ポイント何ですか？

### サンプル③：募集回（約32秒・週1本だけCTAあり）

> 「取材とか、うちみたいな小さい店でもいいんですか？」
> ってよく聞かれるんですけど、**むしろそういう店が聞きたい**です。
>
> 個人事業主を年間1,000人取材してます。
> 話すのは、お金のこと・集客のこと・この先どうするかのこと。
>
> 特別なエピソードとか、いらないです。
> 「普通にやってます」って人の普通が、一番参考になるので。
>
> 個人でお店をやってる方の取材、いま募集してます。
> プロフィールのリンクから、一言送ってもらえたら大丈夫です。

> **Threads用の文章版**は `operations/templates/threads_content_calendar.md` の台本を流用。
> 短尺動画は文章版の「一番おいしい1エピソード」だけを切り出したものと考える。
> **同じ素材を「話す＝TikTok」「書く＝Threads」で二重に使うのが本プレイブックの核心。**

## 5. プロフィール設計（Phase 0で必ず書き換える）

```
【名前欄】
〇〇｜地域のお店を取材する人

【自己紹介】
年間1,000人の個人事業主を取材してます
サロン・整体院・個人店オーナーの本音を発信
▼取材のご依頼・ご相談はこちら
```

**リンクは1本だけ**（公式LINE）。リンクまとめサービスを挟まない — 1クリック増えるごとに到達は半分になる。

## 6. コメント → DM → アポの流れ（Sora担当）

### STEP 1：コメントは全部返す（投稿当日中）
返信は必ず**問いかけで終える**。会話が続いた相手だけが見込み客。

### STEP 2：プロフィール確認
- 個人事業主か（サロン・整体・美容・個人店）
- 地域は対象内か
- Instagram／LINEへの導線があるか

### STEP 3：DM打診
> コメントありがとうございます！
> 〇〇（業種）をされてるんですね😊
> よかったら少しお話聞かせてもらえませんか？
> 取材のご案内もできるので、DM送っても大丈夫ですか？

### STEP 4：以降は既存フローに合流
DM許可後の説明文は、Ryo設計の既存スクリプトを使用。
アポ確定後は **Kaiの日次ログに「TikTok経由」タグで記録** し、初回電話フローへ引き継ぐ。

> **重要**：ここで新しい営業フローを作らないこと。既存の初回電話→インタビュー→FP面談の流れに合流させる。流入経路タグだけが新しい。

| 日付 | フォーマット | フック | 再生 | いいね | コメント | プロフ遷移 | LINE登録 |
|------|------------|--------|------|--------|---------|-----------|---------|
| | ①取材本音 / ②問いかけ / ③ノウハウ | | | | | | |

**月末にやること**：`プロフ遷移 ÷ 再生` が最も高かったフックを特定し、翌月はその型を厚くする。
**再生数が最大の本ではなく、LINE登録が最大の本を正解とする。**

## 9. 禁止事項

- 台本なしで撮る（収録が長引き、翌週から続かなくなる）
- 35秒を超える動画を作る（完視聴率が落ち、配信量が減る。1分以上は1万人到達後）
- 毎回CTAを入れる（中身が削られ、完視聴率とコメント率が両方落ちる）
- フォロワーの購入・相互フォロー（転換率が壊れ、配信先の判定も濁る）
- ジャンルを広げてバズを狙う（導線に乗らない層が増えるとターゲティングが濁る）
- 保険・金融の断定的な発信
- 取材した方の情報を、許可なく特定できる形で出す
