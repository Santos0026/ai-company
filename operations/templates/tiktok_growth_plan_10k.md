## 1. 1万人に必要な「総再生数」を先に出す

フォロワー増加は、感覚ではなく次の式で決まります。

```
増えるフォロワー数 ＝ 総再生数 × フォロワー転換率
```

**フォロワー転換率**（再生のうち何%がフォローするか）の目安：

| 状態 | 転換率 | 意味 |
|------|--------|------|
| ジャンルが混ざっている | 0.3〜0.5% | 見て終わり。誰の何のアカウントか伝わっていない |
| 一般的なアカウント | 0.5〜1.0% | 内容は良いが、次も見たい理由がない |
| **専門特化＋シリーズ化** | **1.0〜3.0%** | 「この人の続きが見たい」が発生している |

**+7,400人に必要な総再生数**

| 転換率 | 必要な総再生数 |
|--------|---------------|
| 0.5% | 1,480,000回 |
| 1.0% | 740,000回 |
| **2.0%** | **370,000回** |

### これを投稿本数で割ると、現実が見えます

| 投稿ペース | 6ヶ月の本数 | 転換率1%なら必要な平均再生 | 転換率2%なら必要な平均再生 |
|-----------|-----------|--------------------------|--------------------------|
| 週2〜3本 | 約65本 | **11,400回/本** | **5,700回/本** |
| **週5本** | **約130本** | **5,700回/本** | **2,850回/本** |

> **結論：週2〜3本のままだと、1本あたり平均1万再生を6ヶ月出し続ける必要がある。これは現実的ではない。**
> **本数を倍にすれば、必要な1本の実力は半分になる。1万人到達の可否は、ほぼここで決まります。**

## 2. 最大の発見：制約は「本数」ではなく「撮影時間」だった

オーナーの制約は「週2〜3本が限界」でしたが、正確には **「撮影に週90分しか使えない」** です。
この2つは別物で、そこに突破口があります。

```
【従来の想定】                    【変更後】
90分の収録                        90分の収録
  └ 60〜90秒の動画を3本            └ 20〜35秒の動画を10〜12本
      = 週3本                          = 週5本（＋ストック）

撮影時間：同じ90分。本数：約2倍。
```

**なぜ短尺のほうが本数を稼げるのか**：60〜90秒の台本は覚えるのも撮り直すのも重い。20〜35秒なら1本あたり実撮影3〜5分。言い直しも軽い。90分あれば10本以上撮れます。

**しかも短尺のほうが伸びます**：TikTokの配信量を決める最重要指標は**視聴完了率**です。

```
60秒の動画で30%完視聴  →  平均視聴18秒  → 配信が伸びない
25秒の動画で80%完視聴  →  平均視聴20秒  → 配信が伸びる ✅
```

同じ平均視聴時間でも、**完視聴率が高いほうが「最後まで見られた良い動画」と判定されます。**

> ⚠️ **既存プレイブックの修正**：`tiktok_content_playbook.md` に「60〜90秒」と書いていましたが、
> **1万人到達を目標にするなら20〜35秒が正解**です。当該ファイルを修正済み。
> （なお、Creator Rewards Programの報酬対象は1分以上の動画なので、**1万人到達後**に長尺へ切り替えます。順番が逆にならないよう注意）

## 3. 伸びるか伸びないかを決める5つのレバー（優先順）

### レバー1：テーマを1つに固定する（最重要・今日やる）

TikTokは「この動画を誰に配信するか」を、**アカウントの直近の反応データ**から判断します。
ジャンルが混ざっていると配信先が定まらず、どれだけ投稿しても伸びません。

**固定するテーマ**：**「地域の個人事業主・お店オーナーのリアル」**
これ以外の動画は投稿しない。日常・趣味・時事ネタは、伸びても**配信先を濁らせる害のほうが大きい**。

**判断基準**：「サロンや整体院のオーナーが見て、自分ごとだと思うか？」がNoなら投稿しない。

### レバー2：シリーズ化する（フォロワー転換率を2倍にする）

単発でバズっても、フォローはされません。**「続きが見たい」がないから**です。

```
✕ 単発            「整体院オーナーの話をします」
◎ シリーズ  「取材で聞いた本音 #37 — 月商80万の整体院オーナー編」
```

冒頭とテロップに**必ず通し番号を入れる**。番号があるだけで「他も見たい」が発生し、
プロフィール遷移 → 過去動画の連続視聴 → フォロー、という流れが生まれます。

**転換率0.5%と2%の差は、ほぼこの一点で決まります。**

### レバー3：冒頭2秒を作り込む（再生数そのものを決める）

視聴者は2秒で離脱を判断します。ここで抜けられたら、内容がどれだけ良くても配信は止まります。

**やること**
- **発話とテロップを同時に出す**（音声オフで見ている人が半分いる）
- 状況説明から始めない。**いきなり結論・いきなりセリフ**から入る

```
✕「今日は整体院のオーナーさんに取材した話をします」（説明から入っている）
◎「『一番怖いのは、売上じゃなくて自分が倒れることです』」（いきなりセリフ）

✕「個人事業主の方に多い悩みなんですけど」
◎「独立して3年、初めて人に相談したって言われました」
```

**フックは動画ごとに変える。テーマは固定、フックは実験。** これが改善サイクルの本体です。

### レバー4：コメントが割れる問いで終える

コメント率は配信量に直結します。そして**コメントが最も伸びるのは「答えが割れる問い」**です。

```
✕「参考になったらコメントください」        → 割れない。誰も書かない
◎「来ない日と来すぎる日、どっちがしんどい？」 → 割れる。書きたくなる
◎「独立して一番後悔したこと、何ですか？」    → 全員が違う答えを持っている
```

### レバー5：コメントに動画で返信する（撮影ゼロで本数が増える）

TikTokの「コメントに動画で返信」機能を使います。

- **ネタを考える時間がゼロ**（コメントがそのまま企画になる）
- コメントした本人と、そのやり取りを見たい既存視聴者が**再訪する**
- 会話が可視化され、アカウントの人間味＝**顔売りの本体**が伝わる

**週5本のうち1〜2本はこれで埋める。** 実質、撮影負荷を増やさずに本数が増えます。

## 4. 1.7万フォロワーのThreadsを使う（他人が持っていない武器）

ゼロから1万人を作るより、**すでに1.7万人いる場所から連れてくるほうが速い**。

| 施策 | 頻度 | 内容 |
|------|------|------|
| Threads → TikTok誘導 | 週1回 | 「動画版も撮ってます」と自然に導線を置く |
| 取材の裏側を先出し | 隔週 | Threadsで予告 → TikTokで本編 |
| プロフィール相互リンク | 常時 | 両アカウントのプロフィールに相互リンクを設置 |

**1.7万人の1%が動いただけで+170人。** これを月1回やるだけで、6ヶ月で約1,000人。目標の13%を、追加の撮影ゼロで確保できます。

## 5. 90日ロードマップ

### Month 1（Day 1〜30）：土台を作る — 伸ばすより「整える」

- [ ] **過去投稿の棚卸し**：テーマ外の動画を非公開にする（配信先を濁らせているため）
- [ ] プロフィールを「取材者」ポジションに書き換え（文言は `tiktok_content_playbook.md`）
- [ ] **固定動画3本**を設定：①自己紹介 ②最も反応が良かった1本 ③シリーズの第1話
- [ ] シリーズ名と通し番号のフォーマットを決定
- [ ] 収録方式を**短尺まとめ撮り**に変更（90分で10本）
- [ ] 週5本投稿を開始（うち1〜2本はコメント返信動画）
- [ ] 投稿時間を固定（推奨：**21:00〜22:30**／個人事業主が店を閉めた後）
- [ ] **Month 1の判定**：平均再生1,500回以上／フォロワー転換率0.8%以上

### Month 2（Day 31〜60）：フックを実験する

- [ ] フック3パターンを各週テストし、**完視聴率**で勝ち筋を特定
- [ ] 上位20%の動画に共通する要素を言語化し、台本テンプレに反映
- [ ] 最も伸びた動画の**続編**を作る（伸びた文脈は繰り返し伸びる）
- [ ] Threadsからの送客を月2回実施
- [ ] **Month 2の判定**：平均再生3,000回以上／累計4,500〜5,500フォロワー

### Month 3（Day 61〜90）：勝ちパターンを増産する

- [ ] 勝ちフォーマットに寄せ、実験の比率を落とす（探索3割・増産7割）
- [ ] LIVEを週1回（LIVE視聴者はフォロー転換率が最も高い）
- [ ] **Month 3の判定**：累計7,000〜8,000フォロワー／月間再生10万回超

> **1万人到達の現実的な着地：4〜6ヶ月目。** 週5本・平均3,000再生・転換率1.5%が維持できた場合。
> 週2〜3本のままなら**10〜12ヶ月**。この差が本プランの全てです。

## 6. 毎週見る数字（この4つだけ）

```
【週次グロースレポート】
週：      月    日〜    日
投稿本数：      本
総再生数：          回
① 平均視聴完了率：      %   ← 最重要。配信量を決める
② コメント率：          %   （コメント数 ÷ 再生数）
③ フォロワー転換率：    %   （新規フォロワー ÷ 再生数）
④ プロフィール遷移率：  %
今週の最高完視聴率の本とそのフック：
来週の仮説：
```

**優先順位は ① → ② → ③。フォロワー数そのものは追わない。**
①②が上がれば③は自動的に上がります。逆に、①が低いまま本数だけ増やしても永遠に伸びません。

## 7. やらないこと

- **フォロワーの購入・相互フォロー** — 転換率が壊れ、配信先の判定も濁る。金を払って伸びなくなる最悪手。
- **テーマ外のバズ狙い** — 一時的に再生は出るが、集まった人が次の動画を見ないため、平均指標が下がりアカウント全体の配信量が落ちる。
- **1分以上の動画を今作ること** — Creator Rewardsは1万人到達**後**の話。今は完視聴率が全て。
- **毎日投稿するために台本なしで撮ること** — 質が落ちた本数増加は、平均指標を下げて逆効果。
- **数字を見ずに投稿し続けること** — 週1回の振り返りがない運用は、6ヶ月やっても何も学習しない。

## 8. Jobsからオーナーへ

1万人を取りに行くこと自体には賛成します。1万人は Creator Rewards の解禁だけでなく、
**PR案件・協賛企業への提案力・取材依頼の通りやすさ**という、この事業に直結する信用に変わります。

ただし条件が1つ。**集める1万人が「地域の個人事業主層」であること。**
同じ労力で「誰でもいい1万人」を集めると、16,100円の導線はむしろ弱くなります。
テーマ固定（レバー1）を守るかどうかが、1万人の価値を10倍変えます。

そして最大の変更点はこれです：

> **週2〜3本を、撮影時間を増やさずに週5本にする。**
> 1万人到達の可否は、ここ一点にかかっています。
