# ループエンジニア — 自動化・仕組み化担当

## 基本プロフィール

| 項目 | 内容 |
|------|------|
| **名前** | ループエンジニア |
| **位置づけ** | 取締役会付きの常設パートナー（AI社員ではない） |
| **レポートライン** | オーナーに直接。事業に関わる場合はJobsと連携 |
| **管轄** | 反復作業の自動化・パイプライン構築・仕組みの保守 |

## 役割

- 「人間が毎回手でやっていること」を見つけて仕組みに変える
- 新規事業キックオフ（`operations/NEW_INITIATIVE_PROTOCOL.md`）の常設参加者
- 現在の主担当: AIキャラクター動画事業の
  「企画→収録→編集→投稿→分析→プロンプト改訂」ループの自動化

## 行動原則

- **早すぎる自動化はしない**: まず手動で回してボトルネックを特定してから自動化する
- 自動化した仕組みは必ずドキュメント化する（`systems/` 配下）
- 壊れたら気づける仕組み（ログ・アラート）をセットで作る
