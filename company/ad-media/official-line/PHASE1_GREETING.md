# Phase 1 — あいさつメッセージ ＋ ヒアリング設計

**目的**: 友だち追加直後に「歓迎 → サービス理解 → 分類（タグ付け）→ 最初の案件」までを一気通貫で届ける
**方針**: 学生向けに明るく・短く・タップで完結。送客モデルの肝＝ヒアリングでのタグ付けを最優先。

---

## A. あいさつメッセージ（友だち追加直後 / 叩き台 v1）

> 複数吹き出しに分けて送る想定。絵文字は1吹き出し2〜3個まで。

**① 歓迎**
```
はじめまして😊
「ガクチカ協賛」公式LINEの登録ありがとうございます🎓✨

ここはスマホ1つで参加できる、
"学生限定"のモニターサービスだよ！
```

**② できること**
```
できるのはこの4つ👇
📝 アンケート回答（10分・5,000円〜）
💬 無料面談（オンライン60分〜）
🎤 インタビュー参加（対面/オンライン）
📱 アプリモニター（数日利用でOK）

授業のスキマや通学中に、
生活費・新歓費のちょっとした足しに🍀
```

**③ ヒアリング導入**
```
キミにピッタリの案件を届けるために、
かんたんな質問に答えてね😊
（タップで選ぶだけ・30秒）
```
→ 続けて【B. ヒアリング】の選択肢を提示

**④ 最初のおすすめ（ヒアリング後 or 並行）**
```
＼今おすすめの案件／
🎯 就活オンライン面談モニター
・オンラインで面談するだけ
・1件5,000円 × 4件 = 最大20,000円
・就活の"ガクチカ"にもなる🎓

気になったら「面談」と送ってね！
```

---

## B. ヒアリング（タグ付け）設計

タップ選択式（リッチメニュー/カルーセル/回答ボタン）。回答＝自動タグ付け。

### Q1. 学年は？
`1年` / `2年` / `3年` / `4年` / `大学院・その他`
→ タグ: `学年:1` … `学年:院`

### Q2. 気になる案件は？（複数OK）
`アンケート` / `面談` / `インタビュー` / `アプリモニター` / `とにかく稼ぎたい`
→ タグ: `興味:アンケート` など（複数付与）

### Q3. 温度感は？
`今すぐやりたい🔥` / `良いのがあれば😊` / `まずは情報だけ👀`
→ タグ: `温度:今すぐ` / `温度:検討` / `温度:情報収集`

### 自動付与タグ（本人回答不要）
- 流入元: `流入:IG` / `流入:X` （友だち追加URLの出し分けで判別）
- 登録日 / 案件参加履歴（例: `参加:面談済`）

---

## C. タグ設計一覧（送客の分岐に使う）

| カテゴリ | タグ例 | 使いみち |
|---------|--------|---------|
| 学年 | 学年:1〜4 / 院 | 就活案件は3・4年に厚く配信 |
| 興味 | 興味:面談/アンケート/… | 合う案件だけ届けてブロック防止 |
| 温度感 | 温度:今すぐ/検討/情報収集 | 「今すぐ」に優先送客、他は育成 |
| 流入元 | 流入:IG / X | メディア別の質・CVを比較 |
| 履歴 | 参加:面談済 など | 二重案内を防ぎ、次案件を出す |

---

## D. この設計で狙うKPI（Phase 0と接続）

- アンケート回答率（=タグ化率）**50%以上**
- 追加初日のブロック率を **5%以下**
- 「今すぐ」タグ層の案件クリック率を最大化

---
