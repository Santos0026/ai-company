# Phase 1 — あいさつ ＋ プロフィール登録 ＋ 案件カルーセル

**方針（オーナー確定）**: いきなり案件を売り込まない。
まず **ライトなプロフィール登録** で関係を作り、その後に **案件一覧を横スクロールのカルーセル（リアルな画像付き）** で見せる。
**参考イメージ**: JobPass（ジョブパス）公式LINE — お役立ち → 相談CTA の"押しつけない"導線。

---

## ★ 友だち追加後の全体フロー

```
① あいさつ（歓迎・サービス一言・「まずは登録から」）
        ▼
② プロフィール登録（3問・タップ中心）
     Q1 名前
     Q2 年齢
     Q3 在学校（あいうえお選択）
        ▼
③ 「登録完了！」（サンクス＋次の一手へ誘導）
        ▼
④ 案件一覧カルーセル（横スクロール・リアル画像付き）
        ▼
   各カードの「応募する」→ 送客
```

## ② プロフィール登録（3問）

> ライトに・タップ中心で。名前だけ入力、あとは選択。

### Q1. 名前
```
まずはお名前を教えてね😊
（ニックネームでもOK！）
```
→ テキスト入力を受け取り、プロフィール「名前」に保存

### Q2. 年齢
```
つぎに年齢を教えてね🎂
```
選択肢: `18` / `19` / `20` / `21` / `22` / `23` / `24歳以上`
→ プロフィール「年齢」に保存
→ ※ 18歳以上（成人学生）が対象。18未満が来た場合の分岐は運用で要検討

### Q3. 在学校（あいうえお選択）
```
最後に、通っている学校を選んでね🏫
```
**2段階選択（あいうえお順）**
1. 頭文字の行を選ぶ: `あ行` `か行` `さ行` … `わ行` / `その他・海外`
2. その行の大学リストから選ぶ（→ `在学校マスタ` を参照）
3. 見つからなければ `一覧にない → 入力する` で自由記述

→ プロフィール「在学校」に保存
→ ※ 大学名リストは別途データ整備（`SCHOOL_MASTER` 課題）。まずは提携200大学＋主要大学から

## ④ 案件一覧カルーセル（横スクロール・画像付き）

**実装**: LINEの「カードタイプメッセージ（カルーセル）」＝右→左に流れる横スクロール。
各カードに **リアルな画像/イラスト**（案件イメージ）を必ず載せる。

### カード構成テンプレート
```
┌─────────────┐
│ [案件のリアル画像]      │
│ 🎯 就活オンライン面談    │  ← 案件名
│ 1件5,000円×4=最大2万円   │  ← 報酬（目立たせる）
│ オンラインで話すだけ🎓   │  ← 一言メリット
│ [ 応募する ]           │  ← ボタン→送客/次アクション
└─────────────┘
```

### 初期カルーセル（案件マスタ `CASES.md` と連動）
1. 🎯 **就活オンライン面談モニター**（C001 / 5,000円×4=20,000円）
2. 📝 アンケート回答（10分・5,000円〜）※案件が入り次第
3. 🎤 インタビュー参加（対面/オンライン）※案件が入り次第
4. 📱 アプリモニター（数日利用でOK）※案件が入り次第
5. （末尾カード）🔍 **案件をもっと見る** → メニュー/一覧へ

> ※ 画像は「学生がスマホで面談」等のリアルなイメージを用意（各案件1枚）。
> ※ カード枚数・順番はタグ（学年・興味）で出し分け可能（MAツール利用時）。

---

## タグ設計（案件の出し分け・送客管理に使用）

プロフィール登録＝以下を自動で保持し、案件配信の精度を上げる。

| カテゴリ | 取得元 | 使いみち |
|---------|--------|---------|
| 名前 | Q1 | 呼びかけ・パーソナライズ |
| 年齢 | Q2 | 対象年齢の案件のみ配信・成人確認 |
| 在学校 | Q3 | 大学限定案件・エリア別案件の配信 |
| 学年（任意で追加取得） | 別途 | 就活案件は3・4年に厚く |
| 流入元 | 追加URL出し分け | IG / X の質を比較 |
| 案件履歴 | 応募/参加 | 二重案内防止・次案件の提案 |

---

## KPI（Phase 0と接続）

- **プロフィール登録完了率 60%以上**（3問の離脱を抑える）
- 追加初日のブロック率 **5%以下**
- 案件カルーセルの「応募する」クリック率を最大化

---

## 実装で決めること

1. **配信ツール（最重要）**: この体験（3問登録の保存・あいうえお2段階選択・タグ送客）は
   **LINE公式の標準機能だけでは実現が難しい** → **MAツール（Lステップ / エルメ）推奨**。
   - カルーセル自体は標準の「カードタイプメッセージ」でも可
   - ただし「名前/年齢/学校を保存」「あいうえお分岐」「タグ出し分け」はMAツールが必要
2. **在学校マスタ**（あいうえお順の大学リスト）の整備 → `SCHOOL_MASTER`（次タスク）
3. **案件カード画像**（各案件のリアルなイメージ画像）の準備
4. C001 就活面談の**送客先URL/予約フォーム**
