# 広告事業（メディア運用）公式LINE 構築ロードマップ

**目的**: 新規広告事業のメディア運用で使う公式LINEを、ファネル資産としてゼロから構築する
**ステータス**: アカウント開設済み（中身はこれから設計・実装）
**伴走**: Claude（設計・文面・仕組み） × オーナー（意思決定・ビジネス情報）
**品質監修**: Mio（トンマナ・返信品質） / **統括**: Jobs（AI CEO）

---

## 全体像：メディア → 公式LINE → マネタイズ

```
[メディア（IG/TikTok/YouTube/X等）]
        ↓ 友だち追加（オファー/リードマグネット）
[公式LINE アカウント]
   ├─ あいさつメッセージ（第一印象・特典配布）
   ├─ リッチメニュー（常設導線）
   ├─ ステップ配信（教育→信頼→オファー）
   ├─ 通常配信（関係維持・再来訪）
   └─ タグ/セグメント（反応者の可視化）
        ↓ コンバージョン
[ゴール：商材販売 / 送客 / 案件化 など]
```

---

## 構築フェーズ（この順で一緒に埋めていく）

### Phase 0 — コンセプト設計 ★まずここ
- [ ] 誰に（ターゲット像）
- [ ] 何を提供し、何で稼ぐか（マネタイズモデル）
- [ ] 公式LINEの「1つのゴール（KGI）」と中間KPI
- [ ] 主な流入メディアと想定友だち獲得数

### Phase 1 — アカウント基本設定
- [ ] アカウント名 / ステータスメッセージ / プロフィール文
- [ ] 応答モード（Bot / チャット）と営業時間設定
- [ ] あいさつメッセージ（友だち追加直後）＋登録特典の渡し方

### Phase 2 — 友だち獲得導線（入口設計）
- [ ] リードマグネット（登録特典）の内容
- [ ] 各メディアからの導線・訴求文（プロフィールリンク/投稿CTA）
- [ ] 友だち追加URL / QR / ボタンの設置箇所

### Phase 3 — リッチメニュー設計
- [ ] メニュー構成（6分割 or 4分割）とタップ先
- [ ] デザイン要件（テキスト・配色・アイコン）

### Phase 4 — ステップ配信シナリオ
- [ ] 配信本数・日程（例：Day0〜Day5）
- [ ] 各通の役割（教育 / 実績 / 共感 / オファー）
- [ ] 文面ドラフト（トンマナガイドラインに準拠）

### Phase 5 — セグメント / 自動応答
- [ ] タグ設計（興味・行動・属性）
- [ ] キーワード自動応答（よくある質問・予約導線）

### Phase 6 — 運用設計
- [ ] 通常配信カレンダー（頻度・曜日・テーマ）
- [ ] このメディア専用トンマナガイドライン（Mio監修）
- [ ] NGルール・薬機/景表法など表現チェック観点

### Phase 7 — 計測・改善
- [ ] KPIダッシュボード項目（友だち数/ブロック率/開封/クリック/CV）
- [ ] A/Bテスト対象と週次レビュー体制

---

## いま必要なインプット（Phase 0 を埋めるために）

1. **メディアのジャンル・テーマ**（何を発信するメディアか）
2. **主な流入プラットフォーム**（IG / TikTok / YouTube / X / その他）
3. **マネタイズモデル**（このLINEで最終的に何を成立させるか）
4. **ターゲット層**（年代・性別・悩み/欲求）
5. **既存アセット**（開設済みアカウント名、すでに動いている投稿や特典があれば）

> ↑ ここが埋まれば、Phase 1 の「あいさつメッセージ」から具体ドラフトを一緒に作れます。
