# 案件マスタ（送客先リスト）

公式LINEから送客する広告主案件を管理する。新案件はここに追記し、ステップ配信・自動応答から参照する。

---

## 案件テンプレート

```
### [案件ID] 案件名
- ステータス: 募集中 / 停止中
- ターゲット: （学年・属性）
- 様式: （オンライン面談 / アンケート / インタビュー / アプリモニター）
- 報酬: （単価 × 件数 = 合計）
- 所要時間:
- 送客先: （LP / フォーム / 予約リンク）
- 送客キーワード: （例「面談」）
- 対応タグ: （このタグの学生に配信）
- 注意/コンプラ:
```

## C001 学生 就活オンライン面談モニター

- **正式サービス名（案件先）**: 🌏 **JobPassport（ジョブパス）** ＝ 就活支援サービス
- **ステータス**: 募集中
- **ターゲット**: 学生（成人学生 / 就活を意識する層）
- **様式**: オンライン面談
- **報酬**: 5,000円/件 × 4件 = **合計20,000円（セット）**
- **所要時間**: 1件あたりオンライン面談（時間は要確認）
- **送客先**: https://s.lmes.jp/landing-qr/2010529394-w1FSLnW5?uLand=WLgzIl （JobPassport公式LINE登録LP）
- **プロモーションコード**: `a-0010`（プロフィール登録時に入力）
- **就活完了報告の紹介者欄**: `98`（※JobPassportのコードa-0010と混同しない）
- **詳細フロー**: `C001_JOBPASSPORT_FLOW.md` 参照
- **送客キーワード**: `面談`
- **対応タグ**: 興味=面談 / 温度感=今すぐ・検討
- **訴求軸**: 「就活の練習になる ＋ 報酬20,000円 ＋ ガクチカにもなる」
- **注意/コンプラ**:
  - 「必ず/絶対に稼げる」等の断定表現NG
  - 面談の実施条件（回数・所要・報酬支払い条件）を正確に明記する
  - 18歳以上（成人学生）を対象と明示
