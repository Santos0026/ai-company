# Phase 0 — コンセプト設計（広告主案件 送客メディア）

**モデル**: メディア集客 → 公式LINE で関係構築 → 広告主案件へ送客（リード送客型）
**主な流入**: Instagram / X・Threads
**更新**: 2026-07-22

---

## 1. ファネル全体像

```
[IG / X・Threads で発信]
     │  「もっと詳しく／個別に知りたい人はLINEへ」
     ▼
[友だち追加]
     │  あいさつメッセージ：自己紹介 ＋ 特典 ＋ かんたんヒアリング
     ▼
[セグメント化（タグ付け）]      ← 興味・属性で分岐
     │  ステップ配信：信頼構築 ＋ 「案件」の価値提示
     ▼
[最適な広告主案件へ送客]        ← LP / 申込フォーム / 個別相談
     │
     ▼
[成果（申込・成約）＝ 送客報酬]
```

送客モデルの肝は **「友だちを増やす」ではなく「友だちを"正しく分類"して、合う案件に出す」** こと。
だからこの公式LINEの心臓部は **① ヒアリング設計（タグ）** と **② セグメント配信** になります。

---

## 2. KGI / KPI

| 階層 | 指標 | 役割 |
|------|------|------|
| KGI | 送客成果数（申込・成約） | 事業の売上に直結 |
| KPI① | 友だち追加数 | 入口の量（IG/X運用の成果） |
| KPI② | ブロック率 | 関係性の質（低いほど良い / 目安5%以下） |
| KPI③ | アンケート回答率 | セグメント化の成否（目安50%以上） |
| KPI④ | 案件メッセージのクリック率 | オファーの刺さり具合 |
| KPI⑤ | 送客数 → 成果承認率 | 最終収益効率 |

## 3. 送客型で特に重要な設計ポイント

1. **ヒアリング（タグ付け）を最優先で設計する**
   - 友だち追加直後に「あなたに合う案件を出すための2〜3問」を自然に取る
   - 例：興味カテゴリ / 現状の悩み / 温度感（今すぐ〜情報収集）

2. **案件は"押し売り"にならない見せ方**
   - メディアの信頼を毀損すると友だち全体の価値が下がる
   - 「役立つ情報の中で、自然に案件を紹介する」構成にする

3. **表現コンプライアンス（送客型の最大リスク）**
   - 案件ジャンルにより **薬機法・景表法・金商法** 等の表現規制がかかる
   - 「必ず稼げる」「絶対治る」等の断定表現は送信禁止 → Mio がチェック観点を整備

4. **1メディア＝1トンマナ**
   - IG発の友だちと X発の友だちで温度感が違うため、入口別にタグを分けて後で最適化できるようにする
