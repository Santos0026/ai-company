## 4. ビジネスモデル（公式LINEの役割）

```
[IG / X・Threads で認知]
   →「気になる案件があればLINEへ」
[公式LINE（ガクチカ協賛）]  ← 今回構築
   → 学生を案件にマッチング＝広告主へ送客
[広告主（モニター案件を出す企業）]
   → 成果（面談実施・アンケート回答等）で送客報酬
```

**公式LINEのミッション** = 集めた学生を「学年・興味・温度感」で分類し、
その学生に合う広告主案件へ気持ちよく送客し続けること。
