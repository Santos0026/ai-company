# 信頼性強化プラン — 「運営の実在性」で離脱を防ぐ

**課題（オーナー提起）**:
案件（JobPassport）はしっかりしているのに、ガクチカ協賛には **運営会社・運営者の情報が表に出ていない**。
学生が「なんだこれ？」と調べたときに運営元が出てこず、**そこで離脱・不信** につながる懸念。
（＝ヒトモノチイキには"事務局/運営"の顔があったが、ガクチカ協賛には今それがない）

**作成**: 2026-07-22

---

## 対策の柱（優先度順）

### ① 公式サイト（運営者情報ページ）を作る ★最優先
「ガクチカ協賛」で検索したときに、**ちゃんとした運営元ページ**が出てくる状態を作る。
- 内容：サービス概要 / 運営者情報（会社概要）/ 実績 / よくある質問 / お問い合わせ / 特商法表記 / プライバシーポリシー
- 実装：このリポジトリでHTML作成 → GitHub Pages 等で公開（他事業のLP実績あり：sl-capital / si-partners）
- LINE・Instagramからこのサイトへリンク → 三者が繋がって「実在する運営」に見える

### ② 特定商取引法に基づく表記 ＆ プライバシーポリシー ★必須級
- 学生に**謝礼（お金）が発生する有償のやり取り**があるため、事業者情報の明示が重要。
- 個人事業主でも表記義務あり（法人でなくてもOK）。
- サイトにページとして設置し、LINEのメニュー/あいさつからも辿れるようにする。

### ③ LINEプロフィール・あいさつに"信頼シグナル"を追加
- プロフィール文/あいさつに：**提携200大学・1500団体／利用者600人突破／運営者名** を明記
- 「運営：◯◯（会社名 or 屋号）」「公式サイト：URL」を入れる

### ④ LINE認証済アカウント（青バッジ）を取得
- 未認証 → 認証済にすると、検索表示・広告・**一目でわかる信頼感**。無料・審査あり。

### ⑤ 実績・体験談（利用者の声）
- 「実際に参加した学生の声」「もらえた金額」「就活に役立った例」を数件掲載 → 安心材料に。

### ⑥ 相互リンクで実在性を担保
- Instagram（@gakutika_kyosan）↔ 公式サイト ↔ 公式LINE を相互リンク。
- 検索したときに複数の一次情報がヒットする状態にする。

---

## ①③のために必要なインプット（オーナーからの実情報）

> ⚠️ ここは事実で埋める必要がある（信頼性のためのページで、実在しない情報は載せない）。

- [ ] **運営形態**：法人 / 個人事業主 / これから開業 のどれか
- [ ] **会社名 or 屋号**（例：合同会社◯◯／屋号「ガクチカ協賛」）
- [ ] **代表者名**
- [ ] **所在地**（特商法表記に必要。個人は「請求があれば遅滞なく開示」運用も可だが要検討）
- [ ] **連絡先**（問い合わせメール／必要なら電話）
- [ ] **実績数字の裏付け**（600人・200大学・1500団体は表記して問題ない実数か）
- [ ] **謝礼の条件**（金額・支払方法・支払時期）※サイト/FAQに正確に書くため

## 進め方（提案）
1. 上の実情報をもらう
2. こちらで**公式サイト（会社概要・運営者情報・特商法・プライバシー・FAQ・お問い合わせ）を一気に作成**
3. 公開URLをLINEプロフィール／あいさつ／リッチメニューに接続
4. 並行して認証済アカウント申請・体験談の収集
