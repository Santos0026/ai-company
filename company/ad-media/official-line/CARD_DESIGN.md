# 案件カルーセル カード デザイン仕様

**用途**: エルメの「カルーセル（カードタイプメッセージ）」で送る案件カードの見た目・コピー・画像を定義する。
**作成**: 2026-07-22

---

## 共通仕様（全カード）

| 項目 | 指定 |
|------|------|
| 画像比率 | **1.51:1（横長）** 推奨。例 1024×678px（LINE/エルメ標準） |
| 画像形式 | JPG/PNG、1MB以下目安 |
| ブランドカラー | オレンジ `#F57C20`（メイン）／ 白 ／ アクセント黄 `#FFC93C` |
| タイトル | 全角14文字前後まで（折り返し注意） |
| 説明文 | 2〜3行・報酬を最も目立たせる |
| ボタン | 1〜2個（例：「応募する」「詳細を見る」） |
| トーン | 学生向けに明るく・清潔感・信頼感。派手すぎない |

---

## C001 就活オンライン面談モニター（第1号カード）

### 画像イメージ（リアル）
- **主役**: 大学生がノートPC/スマホで**オンライン面談をしている明るいシーン**
  - 自宅やカフェで、笑顔で画面に向かって話している学生（実写風 or リアルなイラスト）
  - 清潔感のある服装（就活を連想させるが、堅すぎない）
- **重ねる要素**:
  - 右上に **「最大20,000円」** の黄色いバッジ
  - 左上に小さく **ガクチカ協賛ロゴ/マスコット**
  - 下部にオレンジの帯（タイトルが乗る土台）
- **雰囲気**: 前向き・安心・「私にもできそう」と思える明るさ

### コピー（カード内テキスト）
```
タイトル：🎯 就活オンライン面談モニター
説明：
　オンラインで話すだけ！
　1件5,000円 × 4件 = 最大20,000円💰
　就活の"ガクチカ"にもなる🎓
ボタン①：応募する（→ 送客先URL）
ボタン②：くわしく見る
```

### コンプラ注意（Mio観点）
- 「必ず/絶対に稼げる」等の断定表現は使わない
- 報酬は条件（面談実施・全4件）を正確に。誇大表現NG
- 18歳以上（成人学生）対象を明示
