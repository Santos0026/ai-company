# 案件LP用 画像素材

このフォルダに以下のファイル名で画像を置くと、LP（../index.html）に自動反映されます。
（ファイルが無い場合はプレースホルダー表示になります）

- hero.jpg   … JobPassportメインビジュアル（「あなたの1時間に、価値がつく」の画像／横長16:9推奨）
- photo1.jpg … 女性がPCでオンライン面談している写真（4:3推奨）
- photo2.jpg … 男性がスマホでオンライン面談している写真（4:3推奨）
- voice1.jpg … （任意）体験談のアイコン用・学生の顔写真など（正方形）

※ JobPassportのロゴ文字が写り込んだ画像でもOK（正式案件名のため）。
